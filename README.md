# rad-website-beta-v1.0

* `frontend/` — React + Vite app (customer pages, operator console, owner console)
* `backend/` — Express + SQLite API; see [backend/README.md](backend/README.md) for setup, sign-ins and endpoints
* `api/`, `vercel.json` — URL router for the static Vercel deployment

Quick start: `npm run install:all` once, then `npm run dev` in this folder starts the API (:3001) and the UI (:5173) together.
